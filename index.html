📖 Getting Started Guide - Complete Instructions ▼

🚀 Quick Start - 30 Seconds

1️⃣ Go to Quick Invoice tab → Enter client name → Add item → Generate PDF

2️⃣ OR go to Time Tracker tab → Start timer → Stop → Create invoice from tracked hours

⏱️ Time Tracker - Complete Guide

1. Go to 👥 Clients tab → Click + Add Client
2. Enter client name, email, and hourly rate → Click Save Client
3. Go to ⏱️ Time Tracker tab
4. Select project/client from dropdown
5. Type what you're working on → Click ▶️ Start
6. When done → Click ⏸️ Stop → Time is saved automatically
7. Go to 📄 Invoices tab → Create Invoice from Time Entries
8. Select client → Check time entries → Generate Invoice → Download PDF

⚡ Quick Invoice - Complete Guide

1. Go to ⚡ Quick Invoice tab
2. Fill Client Details (Name is required)
3. Set Invoice Details (Number, Issue Date, Due Date)
4. Add Items: Click + Add Item → Enter description, quantity, price
5. Select Currency from dropdown (12 currencies available)
6. Add Tax Rate (%) or Discount if needed
7. Add Notes/Payment Terms (e.g., "Due in 30 days")
8. Click 👁️ Preview to review invoice
9. Click 📄 Generate & Download PDF → Save or email to client

🌍 Language & Currency Guide

🌐 Change Language: Top-right corner dropdown → Select your preferred language
💰 Available Languages: English, Español, Français, Deutsch, हिंदी, العربية, 中文, Русский
💱 Change Currency: Quick Invoice tab → Additional Information → Currency dropdown
🌎 Available Currencies: USD ($), EUR (€), GBP (£), INR (₹), CNY (¥), SAR (﷼), KWD (د.ك), RUB (₽), BDT (৳), JPY (¥), CAD (C$), AUD (A$)

📊 Managing Your Data

📄 View Invoices: Go to Invoices tab → See all your invoices
⬇️ Download Invoice PDF: Click PDF button next to any invoice
✅ Mark as Paid: In Invoices tab → Click "Mark Paid" when client pays
📤 Export Backup: Click Export Data button in header → Saves all your data
📥 Import Backup: Click Import Data button → Select your backup file
🗑️ Delete Items: Click red Delete button next to any client, time entry, or invoice
